트레이딩뷰 지표 만드는 방법은 Pine 에디터에서 Pine Script v6 코드를 작성하고 작업 메뉴의 "차트에 추가"를 선택하는 것이다. 선이나 값을 표시하려면 지표로 만들고, 주문 규칙을 과거 차트에 적용해 보려면 전략으로 만든다.

## Pine 에디터를 연다

오른쪽 도구 모음에서 "Pine" 아이콘을 클릭하면 Pine 에디터가 열린다. 현재 최신 메이저 버전은 Pine Script v6이다(2026년 9월 확인 기준). 첫 줄에 버전을 적고, 다음 줄에서 지표 이름과 차트 위 표시 여부를 정한다.

Pine 에디터는 작업 상태를 자동 저장한다. 에디터를 닫아도 다음에 열 때 열려 있던 스크립트와 저장되지 않은 변경 사항이 복원된다. 이름을 정해 저장하면 여러 규칙을 구분하기 쉽다.

## 이동평균 두 개를 그리는 예

다음 코드는 종가를 바탕으로 20 EMA와 60 EMA를 계산해 차트 위에 그린다. 한 스크립트 안에서 `plot()`을 여러 번 쓰면 선 여러 개를 표시할 수 있다.

```pine
//@version=6
indicator("20·60 EMA", overlay=true)
fast = ta.ema(close, 20)
slow = ta.ema(close, 60)
plot(fast, "20 EMA")
plot(slow, "60 EMA")
```

코드를 작성한 뒤 스크립트 작업 메뉴에서 "차트에 추가"를 선택한다. 차트에 두 선이 나타나면 지표 제목과 각 선의 이름을 확인한다. 20과 60은 제6장 이동평균선 매매법에서 방향과 되돌림을 읽는 예시로 쓰는 기간이다.

## 지표와 전략을 나눈다

`indicator()`로 만든 지표는 이동평균, RSI, MACD, 볼린저밴드처럼 차트에 표시할 값을 계산한다. 브로커 에뮬레이터가 필요하지 않아 전략보다 적은 자원으로 빠르게 실행되며, 지표 자체는 백테스팅에 쓰지 않는다.

전략은 매수와 매도 주문이 들어간 스크립트다. `strategy()`로 작성한 스크립트는 차트 하단의 "Strategy Tester"에서 과거 차트에 적용된 결과를 확인한다. 선을 그리는 목적과 주문 규칙을 시험하는 목적을 먼저 나누면 시작 코드를 고르기 쉽다.

## 규칙을 코드로 옮기는 순서

먼저 자연어로 규칙을 적는다. 예를 들면 "20 EMA가 60 EMA 위에 있고 가격이 60 EMA 위일 때만 매수 신호를 본다"처럼 조건을 한 문장으로 만든다. 그다음 각 말을 가격 비교와 지표 계산으로 나눈다.

차트에 표시할 값부터 코드로 만든 뒤 한 조건씩 더한다. 두 이동평균이 올바른 위치에 그려지는지 먼저 확인하고, 교차나 종가 위치 같은 조건을 붙이는 순서다. 표시만 필요한 단계에서는 지표로 두고, 진입과 청산 주문을 모두 문장으로 정한 뒤 전략 형태를 검토한다.

## 저장하고 다시 확인한다

스크립트 이름에는 지표와 기간을 함께 적을 수 있다. 차트에 추가한 뒤 심볼과 시간 프레임을 바꾸어도 코드가 현재 차트 봉을 기준으로 다시 계산한다. 어느 봉 단위에서 쓰기로 만든 규칙인지 이름이나 설명에 남긴다.

여러 지표를 한 코드에 넣을 때는 계산값마다 `plot()` 이름을 붙인다. 설정 화면과 데이터 창에서 어떤 값인지 알아보기 쉬워진다. 추세, 진입, 청산 가운데 코드가 맡는 역할도 설명에 적어 둔다.

## 처음 한다면 이 순서로

1. 오른쪽 도구 모음의 "Pine"을 연다.
2. Pine Script v6 선언과 지표 이름을 적는다.
3. 계산식과 `plot()`을 작성한다.
4. 작업 메뉴에서 "차트에 추가"를 선택한다.
5. 주문 규칙까지 만들 때는 전략과 "Strategy Tester"를 쓴다.

## 책에서 이어지는 것

20·60 EMA가 맡는 방향과 진입 기준은 제6장 이동평균선 매매법에서 이어진다. 여러 지표의 조건을 한 규칙으로 묶고 얼러트로 연결하는 과정은 제11장 지표 조합 전략에서 다룬다.
