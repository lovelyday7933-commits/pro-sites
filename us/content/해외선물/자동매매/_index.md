해외선물 자동매매 프로그램은 차트를 대신 예측하는 프로그램이 아니라, 사람이 정한 규칙을 매번 같은 방식으로 실행하는 장치다. 퇴근 뒤나 새벽에 차트를 계속 보기 어렵다면 방향·진입·청산·계약 수·운영 시간을 먼저 정하고, 이를 신호와 주문으로 연결하면 된다.

## 자동매매가 하는 일

자동매매의 핵심은 반복이다. 같은 조건이 완성되면 같은 방향과 계약 수로 진입하고, 정해 둔 가격에서 포지션을 닫는다. 차트를 보고 그때마다 판단하는 부분을 줄이고, 미리 쓴 문장을 프로그램이 읽을 수 있는 조건으로 바꾸는 방식이다.

자동매매는 세 부분으로 나뉜다. 첫째는 언제 사고팔지 정한 규칙이다. 둘째는 조건이 맞았다는 사실을 알리는 신호다. 셋째는 그 신호를 시장가·지정가·Stop 같은 주문으로 바꾸는 실행 부분이다. 세 부분을 나누어야 신호가 생긴 이유와 실제 주문 내용을 각각 확인할 수 있다.

## 규칙에서 신호와 주문까지

예를 들어 “15분봉에서 20 EMA가 60 EMA 위에 있고, 5분봉 MACD선이 0선 위에서 시그널선을 위로 교차한 봉이 마감되면 1계약을 매수한다”라고 적을 수 있다. 여기에 “되돌림 저점 아래 2틱에서 청산하고, 정한 목표 또는 반대 교차 중 먼저 오는 조건에서 정리한다”를 붙이면 하나의 규칙이 된다.

프로그램은 이 문장을 계산식으로 바꾸어 봉이 마감될 때마다 검사한다. 조건이 참이면 매수 신호를 만들고, 주문 부분은 계약 수와 주문 종류를 읽어 증권사 주문 기능이나 API로 전달한다. 매도 규칙은 방향과 비교 조건을 반대로 적는다.

## 문장으로 먼저 적는 이유

『해외선물 수익내는 매매법』 제11장은 규칙을 추세 확인·진입 신호·청산 규칙으로 나눈다. “어느 때만 보고, 어느 봉에서 들어가며, 어디서 손절하고, 어디서 정리한다”라는 문장에 빈칸이 없어야 코드로 옮길 수 있다.

“강해 보이면 매수”처럼 사람마다 해석이 달라지는 말은 계산 조건이 되기 어렵다. 시간 단위, 지표 값, 봉 마감 여부, 계약 수와 운영 시간까지 적으면 같은 차트를 다시 보아도 같은 답이 나온다. 파인 스크립트 전략으로 작성한 뒤 트레이딩뷰의 “Strategy Tester”에서 규칙대로 사고판 기록을 확인할 수도 있다.

## 주문으로 연결하는 세 가지 길

첫 번째는 트레이딩뷰 얼러트와 웹훅이다. 파인 스크립트 전략이나 지표가 조건을 찾으면 얼러트가 발생하고, 웹훅이 사용자가 정한 주소로 메시지를 보낸다. 메시지를 받은 프로그램은 내용을 해석해 증권사 API 주문으로 바꾼다.

두 번째는 국내 증권사의 공식 API다. 한국투자증권 KIS Developers에는 해외선물옵션 주문과 계좌 API가 있고, LS증권 OPEN API에는 “해외선물” 서비스 분류가 있다. 프로그램이 시세를 받고 조건을 직접 계산한 뒤 주문과 미결제 상태를 관리하는 구조를 만들 수 있다.

세 번째는 증권사 주문 기능을 쓰는 방법이다. 진입 뒤 손절용 Stop과 익절용 지정가를 OCO로 묶거나 트레일링 스탑을 설정한다. 이 방법은 신호 계산 전체를 맡기기보다, 진입 뒤의 청산 규칙을 주문 화면에 미리 넣어 두는 데 알맞다. 거래소에 따라 쓸 수 있는 주문 종류가 다르므로 거래할 상품의 주문 화면에서 지원 범위를 확인한다.

## 네 장에서 이어서 볼 내용

“트레이딩뷰 웹훅 자동매매” 장에서는 얼러트 메시지와 HTTP POST 전달 방식을 다룬다. “해외선물 자동매매 전략” 장에서는 제11장의 세 규칙 세트를 방향·진입·청산·계약 수·시간대로 정리한다.

“해외선물 API 자동매매” 장에서는 KIS Developers와 LS증권 OPEN API의 공식 범위를 살핀다. “해외선물 자동매매 주문 스탑 OCO” 장에서는 시장가·지정가·Stop·Stop Limit·Trailing Stop·OCO를 규칙에 붙이는 방법을 설명한다.

## 처음 한다면 이 순서로

1. 거래할 상품과 차트 시간 단위를 하나씩 정한다.
2. 방향·진입·청산·계약 수·켜고 끄는 시간을 문장으로 쓴다.
3. 파인 스크립트 전략과 “Strategy Tester”로 진입·청산 기록을 확인한다.
4. 얼러트·웹훅 또는 증권사 공식 API 가운데 연결 방법을 정한다.
5. 주문 종류와 미결제 확인, 하루 실행 횟수를 한 묶음으로 시험한다.

## 책에서 이어지는 것

규칙을 추세·진입·청산으로 나누고 자동매매 조건으로 옮기는 방법은 제11장 지표 조합 전략에 있다. 주문과 포지션 청산은 제4장 주문과 청산, 켜고 끄는 시간과 하루 횟수는 제14장 나만의 매매 루틴에서 이어진다.
