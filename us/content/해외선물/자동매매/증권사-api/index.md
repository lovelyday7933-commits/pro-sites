해외선물 API 자동매매는 증권사가 제공하는 공식 접점을 이용해 시세 조회, 조건 판단, 주문, 계좌 확인을 이어 붙이는 방식이다. 국내에서는 한국투자증권 KIS Developers와 LS증권 OPEN API에서 해외선물 관련 공식 분류를 확인할 수 있다.

## API 자동매매의 네 단계

첫 단계는 시세를 받는 일이다. 프로그램은 거래할 상품과 월물의 가격 정보를 읽고 봉이나 지표 계산에 쓸 데이터로 정리한다. 트레이딩뷰 웹훅을 신호원으로 쓴다면 이 단계 일부를 트레이딩뷰 전략이 맡고, 주문 프로그램은 전달된 종목과 가격부터 읽는다.

둘째는 조건 판단이다. 15분봉 방향, 5분봉 진입 신호, 실행 시간, 하루 횟수와 계약 수를 검사한다. 셋째는 조건에 맞는 주문 종류와 수량을 정해 공식 주문 API로 보낸다. 넷째는 계좌 API나 주문 조회 기능으로 미체결 주문과 미결제 포지션을 확인한다.

## 한국투자증권 KIS Developers

한국투자증권의 KIS Developers는 국내주식, 국내선물옵션, 해외주식, 해외선물옵션, 장내채권으로 API를 나누어 공식 제공한다. “해외선물옵션” 분류에는 주문과 계좌 기능이 있으며 주문, 정정취소주문, 당일주문내역조회, 미결제내역조회 같은 항목이 포함된다(2026년 9월 확인 기준).

자동매매 프로그램은 주문 전에 계좌 상태와 기존 미결제 수량을 읽고, 규칙이 만든 방향과 계약 수를 주문 요청으로 바꿀 수 있다. 주문 뒤에는 당일 주문 내역과 미결제 내역을 다시 읽어 프로그램이 기록한 상태와 맞춘다. 청산할 때는 같은 월물과 수량으로 반대 주문을 만들고, 남아 있는 청산 주문도 함께 관리한다.

한국투자증권은 eFriend API도 공식 안내한다. 이 API는 REST 방식이며 국내 주식·파생과 해외 주식·파생 매매 기능을 제공한다고 설명되어 있다(2026년 9월 확인 기준). 구현할 때는 사용할 공식 문서의 해외선물옵션 분류와 주문·계좌 항목을 기준으로 요청 형식을 맞춘다.

## LS증권 OPEN API

LS증권 OPEN API 공식 사이트에는 업종, 주식시세, 주식계좌(주문), 국내파생 시세, 국내파생 계좌(주문)와 함께 “해외선물”이 독립된 서비스 분류로 표시된다(2026년 9월 확인 기준). 해외선물 자동매매를 검토할 때는 이 분류 안에서 제공되는 조회와 주문 항목을 확인해 프로그램 구조에 연결한다.

두 증권사의 이름이 함께 나온다고 API 형식이 같다는 뜻은 아니다. 종목 코드, 월물 표기, 주문 필드와 응답값은 선택한 증권사의 공식 문서에 맞추어 작성한다. 한 프로그램에서 증권사를 바꿀 수 있게 만들려면 규칙 계산 부분과 증권사 요청 부분을 나누어 둔다.

## 시세부터 미결제 확인까지

프로그램의 한 번 실행은 “시세 받기 → 조건 판단 → 주문 → 미결제 확인” 순서로 구성할 수 있다. 시세를 받은 시각과 사용한 봉을 기록하고, 조건이 참이면 방향·계약 수·주문 종류를 주문 요청으로 만든다. 주문 응답을 받은 뒤에는 주문 내역을 조회해 접수 상태를 기록한다.

진입이 확인되면 손절과 익절 규칙을 주문으로 만든다. 증권사에서 OCO를 지원하는 상품이라면 두 청산 주문을 한 묶음으로 설정할 수 있다. 전략 조건으로 청산한다면 다음 시세를 받을 때 청산 조건을 계산하고 같은 월물·같은 수량의 반대 주문을 낸다.

프로그램을 다시 켰을 때는 저장해 둔 값만 믿지 않고 계좌의 미결제 내역부터 읽는 순서로 설계한다. 그러면 현재 포지션 방향과 수량을 기준으로 새 신호를 처리할 수 있다. 주문 식별값, 주문 시각, 종목, 방향, 수량과 조회 결과는 한 기록으로 묶는다.

## 계좌와 접속 정보 준비 범위

이 페이지의 근거에서 확인되는 범위는 KIS Developers의 해외선물옵션 주문·계좌 API와 LS증권 OPEN API의 “해외선물” 서비스 분류다. 각 증권사의 계좌 연결, 인증값 발급 화면과 입력 순서는 이 근거에 구체적으로 적혀 있지 않으므로 임의의 메뉴 이름이나 키 이름을 덧붙이지 않는다.

준비 단계에서는 먼저 이용할 증권사와 해외선물 계좌를 정하고, 선택한 공식 개발자 사이트에서 해외선물 문서가 제공하는 인증 및 주문 형식을 따른다. 접속 정보는 주문 프로그램에 보관하고 트레이딩뷰 웹훅 메시지에는 종목·방향·계약 수 같은 신호 값만 넣는다.

## 처음 한다면 이 순서로

1. KIS Developers 또는 LS증권 OPEN API에서 해외선물 공식 분류를 확인한다.
2. 사용할 상품의 시세·주문·계좌 조회 항목을 한 묶음으로 정리한다.
3. 시세를 받아 규칙의 방향·진입·계약 수를 계산한다.
4. 주문 응답과 당일 주문 또는 미체결 상태를 기록한다.
5. 미결제 방향과 수량을 읽은 뒤 청산 주문까지 이어서 시험한다.

## 책에서 이어지는 것

API에 넣을 방향·진입·청산 규칙은 제11장 지표 조합 전략에서 만든다. 반대 주문으로 포지션을 닫는 법과 OCO 구성은 제4장 주문과 청산에서 이어진다.
