# sites — 주식 / 코인 블로그

이 저장소는 **발행물만** 담는다. 생성 파이프라인(헌법·GOLDEN·매트릭스·codex 배관)은
로컬 `144. 자동화 홈페이지/` 에 남고 여기 올라오지 않는다.

```
stock/    Hugo 사이트 (주식)
coin/     Hugo 사이트 (코인)
_themes/  두 사이트가 공유하는 테마 하나
```

## 왜 퍼블릭인가

GitHub Actions 분은 퍼블릭 저장소에서 계량되지 않는다. 프라이빗이면 실행마다 분이 쌓인다.
지금은 Actions 를 쓰지 않지만, 나중에 필요해질 때 요금이 켜지지 않게 퍼블릭으로 둔다.
블로그 원고는 어차피 공개될 글이므로 숨길 이유가 없고, **비밀은 이 저장소에 두지 않는다.**

## 빌드 규칙 — 비용 조항

빌드는 **Cloudflare Pages 가 Hugo 를 직접** 한다. GitHub Actions 는 쓰지 않는다(Actions 분 0).

1. **글마다 빌드하지 않는다.** Hugo 는 어차피 사이트 전체를 다시 짓는다. 글 1개를 위한 빌드와
   20개를 위한 빌드의 비용이 같다. 예약 슬롯에 맞춰 하루 3회만 짓는다
2. **예약 발행 = 미래 `publishDate` + `buildFuture = false` + 슬롯마다 빌드.**
   빌드하는 그 순간 시각이 지난 글만 구워진다. 즉 **빌드가 곧 발행**이다
3. 빌드를 깨우는 것은 **CF Pages Deploy Hook** 이고, 그걸 치는 것은 **CF Worker 크론**이다.
   GitHub 예약 워크플로가 아니다 — 저장소가 60일 조용하면 자동으로 꺼지고 실행이 5~20분 밀린다
4. **되커밋하지 않는다.** 되커밋은 자기 트리거 무한 루프의 재료다. 재고는 파일에서 계산한다
5. **PAT 로 push 하지 않는다.** 훅은 빌드만 깨우고 저장소를 건드리지 않는다
6. ⛔**Deploy Hook URL 을 이 저장소에 넣지 않는다.** 그 URL 하나면 누구나 빌드를 돌릴 수 있다
   (Worker Secret 에 둔다 — 로컬 `144/ops/cron-build/`)
