키움 자동매매 설정은 "조건검색"으로 종목을 찾고, "성과검증"으로 조건식의 과거 모습을 본 뒤, "자동감시주문"에 감시조건과 주문 설정을 저장하는 순서로 시작한다. 더 세밀한 계산과 기록이 필요하면 Open API+ 또는 REST API로 직접 구성할 수 있다.

## 조건검색으로 종목 찾기

키움증권 "조건검색"은 지정한 여러 조건과 일치하는 종목을 실시간으로 검색하는 화면이다. 기술적분석·패턴분석·재무분석·순위분석·시세분석 등의 지표를 조합할 수 있으며, 검색된 종목은 관심종목으로 등록할 수 있다.

먼저 찾고 싶은 상태를 문장으로 쓴다. "짧은 이동평균선이 긴 이동평균선 위에 있고 거래량 조건도 맞는 종목"처럼 종목 범위와 지표 조건을 분리한다. 그다음 조건검색 화면에서 같은 내용을 조합하고 실시간 검색 결과가 의도한 종목을 보여 주는지 확인한다.

골든크로스처럼 순간에 성립하는 조건과 짧은 선이 긴 선 위에 있는 상태는 서로 다르다. 어느 쪽을 찾는지 문장에 적어 두면 검색 결과를 해석하기 쉽다. 검색된 종목을 바로 주문과 잇기 전에 관심종목으로 모아 신호 발생 시각과 당시 값을 기록해 볼 수도 있다.

## 성과검증으로 과거 확인하기

조건식을 만들었으면 "성과검증" 화면으로 간다. 이 화면은 작성한 조건식의 신뢰도를 검증하는 기능이다. 일단위 검증은 최대 10년, 분단위 검증은 최대 6개월까지 가능하다(2026년 9월 확인 기준).

검증할 때는 진입 조건만 보지 않는다. 신호가 발생한 뒤 언제 결과를 볼지, 같은 종목에서 신호가 반복되면 어떻게 셀지, 비교 기준을 무엇으로 둘지를 먼저 정한다. 조건값을 여러 번 바꿨다면 어떤 값을 언제 검사했는지도 기록한다.

골든크로스, 거래량 증가, 이격도 같은 신호는 서로 뜻이 다르다. 과거 결과와 함께 신호가 이미 움직인 상태를 나타내는지, 이동평균선에서 떨어진 정도를 나타내는지 읽는다. 이 사이트의 신호별 실측도 조건 후보를 비교하는 출발점으로 쓸 수 있다.

## 자동감시주문 설정하기

"자동감시주문"은 보유종목 또는 특정종목의 감시조건과 주문 설정을 저장한 뒤, 유효기간 동안 키움증권 감시 시스템이 조건을 확인하고 충족 시 자동으로 주문하는 기능이다. 서버자동스탑로스라는 이름으로도 안내된다.

감시 가능한 시간은 KRX 정규장 09:00~15:20, 넥스트레이드 08:00~20:00이다(2026년 9월 확인 기준). 감시 가능한 종목은 코스피·코스닥·신용종목·ETF·ELW·ETN이다. 자신이 쓸 시장과 시간을 고른 뒤 매수 또는 매도 조건, 주문 설정, 유효기간을 저장한다.

HTS·MTS 화면을 꺼도 키움증권 서버가 최대 90일 동안 감시와 자동주문을 이어 간다(2026년 9월 확인 기준). 유효기간도 달력 기준 최대 90일이다(2026년 9월 확인 기준). 설정 뒤에는 만료 날짜와 감시 상태를 일정에 적어 두고 다시 확인한다.

감시조건 수는 보유종목 자동매도 50개, 신규종목 자동매수 50개, 잔고편입 자동매도 5개다(2026년 9월 확인 기준). 종목 수가 아니라 어떤 감시 구분에 조건을 저장하는지 나눠 세면 관리하기 쉽다.

## Open API+ 사용 등록 경로

직접 프로그램을 만들려면 Open API+ 사용 등록부터 한다. 공식 안내 경로는 홈페이지 > 고객서비스 > 다운로드 > Open API > 키움 Open API+다. 이 경로에서 사용등록을 마친 뒤 모듈을 다운로드하고 설치한다.

Open API+ 방식에서는 자신의 프로그램이 시세와 계좌 정보를 읽고 정한 조건을 계산하도록 구성할 수 있다. 조건 성립 뒤 주문 요청과 처리 결과를 기록하는 순서도 코드로 잇는다. 먼저 조회와 기록을 구성한 뒤 주문 단계에 필요한 입력값을 연결하면 각 단계가 분명해진다.

조건검색과 자동감시주문으로 해결되는 일이라면 HTS 기능부터 구성하고, 계산 순서나 기록 형식을 더 세밀하게 만들 때 API 범위를 살핀다. 두 방식 모두 규칙과 주문 금액은 사용자가 먼저 정한다.

## REST API 등록과 거래 범위

키움 REST API는 키움 계좌를 보유하고 HTS ID를 연결한 고객이 이용할 수 있다. 공식 경로는 홈페이지 > 트레이딩 채널 > 키움 REST API다. 여기에서 사용 등록을 진행한다.

위탁종합계좌뿐 아니라 중개형ISA·연금저축·비과세종합계좌도 신청할 수 있다. 현재 거래 가능한 상품은 국내주식이며 ETF와 ETN을 포함한다(2026년 9월 확인 기준). 만들려는 프로그램의 거래 상품이 이 범위에 들어가는지 먼저 확인한다.

발급 순서는 키움 OpenAPI 포털에서 사용 신청 → 앱(App) 등록 → 등록한 앱에서 App Key와 App Secret 확인·발급이다. 인증 정보는 프로그램 설정에서 읽도록 구성하고 주문 규칙과 분리해 관리한다.

## 처음 한다면 이 순서로

1. "조건검색"에서 지표를 조합하고 실시간 검색 결과를 확인한다.
2. "성과검증"에서 기간과 결과 확인 기준을 정해 조건식을 살핀다.
3. "자동감시주문"에서 감시 시간, 조건, 주문 설정, 유효기간을 저장한다.
4. 더 세밀한 계산이 필요하면 Open API+와 REST API의 거래 범위를 비교한다.
5. 만료 날짜, 감시 상태, 주문 기록을 정기적으로 확인한다.
